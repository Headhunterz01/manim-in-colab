# 🎬 Manim in Google Colab 

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/drive/1dD-R8x7Ru30QzBU5aZ_JJavpvMObHcgG?usp=sharing)

无需在本地配置复杂的 LaTeX 和 Cairo 环境，只需点击上方的徽章，即可在 Google Colab 中一键运行 [Manim Community](https://www.manim.community/) (数学动画引擎)！

本指南和配套的 Notebook 提供了从零开始安装、配置到渲染复杂动画（如引力助推动画）的完整工作流。

---

##  快速开始

1. 点击上方的 **[Open In Colab]** 徽章。
2. 在 Colab 菜单栏中选择 **代码执行程序 (Runtime)** -> **全部运行 (Run all)**。
3. 等待环境安装完毕，即可在下方单元格看到渲染出的动画视频！
